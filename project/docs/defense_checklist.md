# Краткий сценарий демонстрации на защите

1. В терминале перейти в каталог проекта и выполнить `python run.py`.
2. Открыть `http://127.0.0.1:8000`.
3. Загрузить `data/sample_sales.csv` без фильтра. Ожидается: 10 строк, 6 столбцов, 2 пропущенные ячейки, заполненность 96,67%.
4. Вернуться к форме и загрузить тот же файл с фильтром `revenue`, минимум `20000`, максимум `90000`. Ожидается: 4 строки с ID 1001, 1002, 1005 и 1009; один пропуск; заполненность 95,83%.
5. Нажать «Скачать результат CSV» и проверить, что в файле остались только четыре строки.
6. Для негативного сценария попробовать выбрать неподдерживаемый файл или задать текстовый столбец `region` как фильтр. Приложение должно показать понятную ошибку без аварийного завершения.
7. Для проверки доступности открыть `http://127.0.0.1:8000/health`; ожидается JSON `{"status": "ok"}`.

Полный автоматизированный набор запускается командой `PYTHONPATH=. pytest -v` из каталога проекта. Ожидаемый результат: 27 passed.
