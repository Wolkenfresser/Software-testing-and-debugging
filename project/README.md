# DataLens Lab — вариант 13

Учебное веб-приложение для интерактивного анализа набора данных по дисциплине «Тестирование и отладка программного обеспечения».

## Возможности

- загрузка таблиц CSV (UTF-8 / Windows-1251) и XLSX;
- проверка формата и размера входного файла;
- определение типов столбцов, количества уникальных значений и пропусков;
- расчёт количества, среднего, медианы, минимума и максимума для числовых столбцов;
- фильтрация числового столбца по включительному диапазону;
- предварительный просмотр первых 15 строк;
- экспорт отфильтрованного набора в CSV;
- экранирование пользовательских данных при выводе HTML и нейтрализация формульных префиксов в экспортируемых текстовых ячейках.

## Требования

- Python 3.10 или новее;
- pandas 2.x;
- openpyxl 3.x;
- pytest 8.x или 9.x для тестов.

Веб-сервер использует стандартную библиотеку Python (WSGI), поэтому отдельный веб-фреймворк не требуется.

## Запуск

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Откройте `http://127.0.0.1:8000`.

## Демонстрация

Пример исходных данных находится в `data/sample_sales.csv`. Загрузите его без фильтра либо укажите `revenue` и диапазон, например от `20000` до `90000`.

## Запуск тестов

```bash
PYTHONPATH=. pytest -v
```

Локальная проверка производительности на 10 000 строк:

```bash
PYTHONPATH=. python scripts/nonfunctional_check.py
```

## Ограничения учебного прототипа

- максимальный размер загружаемого файла — 5 МБ;
- максимальное количество строк — 20 000;
- максимальное количество столбцов — 100;
- последние результаты временно находятся в памяти процесса (до 8 наборов); перезапуск сервера очищает хранилище;
- нет учётных записей, разграничения доступа и постоянного хранения данных;
- для промышленной эксплуатации потребуются аутентификация, CSRF-защита, журналирование, управление жизненным циклом временных наборов и дополнительные проверки входных файлов.

## Структура

```text
analyzer/       загрузчик, аналитический сервис, хранилище, WSGI-веб-приложение
tests/          unit-, интеграционные, функциональные, HTTP- и нефункциональные тесты
scripts/        воспроизводимый нагрузочный замер
data/           демонстрационный CSV
docs/           UML-диаграмма и материалы по архитектуре
```
